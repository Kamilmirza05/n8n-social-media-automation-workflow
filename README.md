# n8n Workflows

This repository contains exported n8n workflow JSON files.

## Included workflows

- AI Agent workflow
- Social Media AI Agent


## Notes

- Keep workflow JSON files under version control so changes are tracked.
- Use GitHub to back up, review, and share workflows across environments.
- Store secrets outside the repo; never commit credentials or environment variables.

## Push to GitHub

1. Create a new GitHub repository.
2. Add the remote:
   `git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git`
3. Push the branch:
   `git branch -M main`
   `git push -u origin main`
